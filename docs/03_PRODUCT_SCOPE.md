# 03 — Product Scope

## Primary: B-Series 3-Compartment Sinks
Use the verified public sample in the data folder.

The demo supports questions around:
- overall wall width
- bowl dimensions
- bowl count
- drainboard count
- drainboard side
- drainboard length
- top gauge/material when verified

## Secondary: Economy Work Tables
Use a small verified set of FBLG / UFBLG records.

Demo filters:
- width/length
- depth
- flat top vs rear up-turn when known
- gauge/material
- base/undershelf

## Secondary: Filler Tables
Use EFT8 records.

Demo filters:
- overall width
- depth
- backsplash
- gauge/material

## Out of scope for version 1
- hand sinks
- underbar systems
- custom chef counters
- fabricated custom stainless
- wood blocks/countertops
- accessories and plumbing compatibility
- complete product family modeling

These can appear as “future catalog expansion” cards but should not contain fabricated recommendations.
