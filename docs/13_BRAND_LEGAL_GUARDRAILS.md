# 13 — Brand / Demo Guardrails

This is an implementation guardrail document, not legal advice.

## Positioning
Label the application as a **private concept demonstration**.

Recommended footer:
> Private concept demonstration by Metamend. Not affiliated with or endorsed by John Boos & Co.

## Data
- Use only the finite public facts already bundled or manually added with provenance.
- Do not build automated scraping into the demo.
- Do not bulk ingest KCL technical assets without permission.
- Link outward to public/technical resources instead of copying restricted libraries.

## Visuals
Prefer original neutral SVG schematics instead of copying product photography.

## Claims
Avoid:
- “official”
- “approved”
- “John Boos AI” as though commissioned
- “complete catalog”
- “guaranteed fit”

Prefer:
- concept
- demo dataset
- verified public specifications
- recommendation based on selected constraints
- verify final specification with manufacturer
