# In-App Assistant Behavior

If a conversational helper is added, its job is to help refine requirements.

Good:
- “You have 80 inches available. Do you need drainboards on both sides, or can one side be omitted?”
- “The demo data contains both 16 x 20 and 18 x 18 bowl families.”

Bad:
- making up a model
- making up code requirements
- claiming code compliance
- claiming a product is currently stocked
- quoting a live price
- claiming an accessory is compatible without data
