# Design System Direction

## Feel
Commercial specification tool, not consumer ecommerce.

## Palette
Use neutral colors chosen by the implementation system. Do not hard-code a proprietary brand palette.
Think:
- warm white
- charcoal
- steel gray
- subtle blue/green accent for verified/fit states
- amber for compromise
- red only for hard failure

## Typography
Strong sans-serif with tabular numerals for dimensions/specs.

## Cards
Low-radius or medium-radius, light border, subtle/no shadow.

## Data density
Readable but information-rich. Desktop tables can be dense; mobile should collapse into labeled rows.

## Visualization
Technical line drawing aesthetic using SVG strokes and dimension labels.

## Motion
Minimal. Use only for wizard transitions, compare tray, and result-state changes.
